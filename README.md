# 🎯 도미노 텍스트 애니메이션

한글 텍스트를 입력하면 3D 도미노로 변환하고, 도미노가 쓰러지는 애니메이션을 감상할 수 있는 웹 애플리케이션입니다.

## ✨ 주요 기능

- **한글 텍스트 지원**: 초성부터 완성된 한글까지 모든 텍스트를 도미노로 변환
- **3D 물리 시뮬레이션**: Cannon.js를 사용한 실제와 같은 도미노 쓰러지기 효과
- **자동 카메라 추적**: 도미노가 쓰러지는 방향을 자동으로 따라가는 카메라
- **슬로우 모션**: 도미노가 쓰러지는 장면을 천천히 감상
- **모던 UI**: 깔끔하고 직관적인 인터페이스

## 🚀 사용 방법

1. 웹 브라우저에서 `index.html` 파일을 엽니다
2. 텍스트 입력란에 원하는 글씨를 입력합니다 (예: "안녕하세요")
3. "도미노 생성" 버튼을 클릭합니다
4. "쓰러뜨리기" 버튼을 클릭하여 도미노 애니메이션을 시작합니다

## 🛠️ 기술 스택

- **Three.js**: 3D 그래픽 렌더링
- **Cannon.js**: 물리 엔진
- **Canvas API**: 텍스트를 도미노 좌표로 변환
- **Vanilla JavaScript**: 순수 자바스크립트로 구현

## 📂 파일 구조

```
domino01/
├── index.html          # 메인 HTML 파일
├── style.css           # 스타일시트
├── main.js             # Three.js 메인 로직
├── textToDomino.js     # 텍스트-도미노 변환 유틸리티
└── README.md           # 프로젝트 설명
```

## 🎨 특징

- **완성도 높은 도미노 배치**: 텍스트의 형태를 정확하게 표현
- **연결성 보장**: 도미노 사이의 간격을 자동으로 조정하여 연쇄 반응 보장
- **그라디언트 색상**: 각 도미노마다 다른 색상으로 시각적 효과 강화
- **반응형 디자인**: 모바일과 데스크톱 모두 지원
